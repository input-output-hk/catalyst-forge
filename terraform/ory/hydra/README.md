# Ory Hydra Terraform Module

Deploy Ory Hydra to Kubernetes using the official Helm chart.
This module follows the patterns used in the Kratos module for consistency.

## Usage

```hcl
module "hydra" {
  source    = "../ory/hydra"

  name      = "hydra"
  namespace = "auth"

  # Optionally pin chart version
  # chart_version = "1.8.0"

  # Map-based values (encoded to YAML before values_yaml)
  values = {
    hydra = {
      config = {
        log = { level = "info" }
      }
    }
  }

  # Optional extra values appended after generated & map-based values for final overrides
  values_yaml = <<-YAML
  hydra:
    automigration:
      enabled: true
  YAML
}
```

Secrets for `hydra.config.secrets.system` are generated by default (length `secret_length`, default 32). Disable via `enable_generate_secrets = false` and provide your own via `values`/`values_yaml`.

### Configuration (hydra.config)

You can pass your Hydra configuration similar to a `hydra.yml` by using `hydra_config`, which is merged under `hydra.config`.

Example (mapping from a `hydra.yml`):

```hcl
module "hydra" {
  source    = "../ory/hydra"
  namespace = "auth"

  hydra_config = {
    log = { level = "info" }
    serve = {
      public = { host = "0.0.0.0", port = 4444 }
      admin  = { host = "0.0.0.0", port = 4445 }
    }
    urls = {
      self = { issuer = "https://forge-test.projectcatalyst.io/.ory/hydra/public" }
      login = "https://forge-test.projectcatalyst.io/.ory/hydra/ui/login"
      consent = "https://forge-test.projectcatalyst.io/.ory/hydra/ui/consent"
      logout = "https://forge-test.projectcatalyst.io/.ory/hydra/ui/logout"
      post_logout_redirect = "https://forge-test.projectcatalyst.io/"
    }
    oauth2 = { pkce = { enforced_for_public_clients = true } }
    strategies = { scope = "exact" }
    ttl = { access_token = "30m", id_token = "30m", refresh_token = "720h" }
    # IMPORTANT: leave `dsn` empty to avoid plaintext secrets; use `dsn_secret` input instead to inject via env.
  }
}
```

### DSN via SecretRef (best practice)

Avoid storing DSN in plaintext config. Provide a SecretRef and the module will inject env var across deployment, job, and cleanup cronjob:

```hcl
dsn_secret = {
  name = "dsn-secret"
  key  = "dsn"
  # env_name = "DSN"  # optional override
}
```

## HTTPRoute (Envoy Gateway)

If deploying with Catalyst Forge and Envoy Gateway, you can enable an HTTPRoute that targets the public service:

```hcl
http_route = {
  enabled = true
  parent_ref = {
    name = var.gateway_name
    namespace = var.gateway_namespace # optional if same as module namespace
    # sectionName = "https" # optional
  }
  hostnames = ["hydra.example.com"]
  # Optional custom rules; default routes "/" to the Hydra public service on port 80
}
```

## Inputs

- `name` (string): Helm release name. Default: `hydra`
- `namespace` (string): Target namespace. Required.
- `repository` (string): Helm repo URL. Default: `https://k8s.ory.sh/helm/charts`
- `chart_version` (string): Helm chart version. Optional.
- `values` (map): Additional values as HCL map; encoded to YAML and applied before `values_yaml`. Default: `{}`.
- `values_yaml` (string): Additional YAML values, applied after generated + map values. Default: empty.
- `hydra_config` (any): Raw Hydra configuration merged under `hydra.config`.
- `dsn_secret` (object): `{ name, key, env_name? }` SecretRef used to inject DSN env into deployment, job, and cronjob.cleanup.
- `create_namespace` (bool): Create namespace. Default: `true`.
- `wait` (bool): Wait for readiness. Default: `true`.
- `timeout_seconds` (number): Helm timeout. Default: `600`.
- `enable_generate_secrets` (bool): Generate Hydra system secret. Default: `true`.
- `secret_length` (number): Generated secret length. Default: `32`.
- `http_route` (object|null): Gateway API HTTPRoute config. Fields: `{ enabled, name?, namespace?, parent_ref { name, namespace?, sectionName? }, hostnames, rules? }`.

## Outputs

- `release_name`: Helm release name.
- `namespace`: Namespace deployed to.
- `chart_version`: Chart version used.
- `generated_system_secret` (sensitive): System secret if generated.

## Requirements

- Terraform >= 1.5.0
- Providers: helm (>= 2.12.1), kubernetes (>= 2.27.0), random (>= 3.6.0)
