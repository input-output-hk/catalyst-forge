# Ory Kratos Terraform Module

Deploy Ory Kratos to Kubernetes using the official Helm chart.
This module is optimized for use with Catalyst Forge and ships with an opinionated configuration.

## Usage

```hcl
module "kratos" {
  source    = "../ory/kratos"

  name      = "kratos"
  namespace = "auth"

  # Optionally pin chart version
  # chart_version = "1.1.0"

  # Map-based values (encoded to YAML before values_yaml)
  values = {
    kratos = {
      config = {
        log = { level = "debug" }
      }
    }
  }

  # Optional extra values appended after generated & map-based values for final overrides
  values_yaml = <<-YAML
  kratos:
    automigration:
      enabled: true
  YAML
}
```

Secrets for `kratos.config.secrets.{cookie,cipher,default}` are generated by default (length `secret_length`, default 32). Disable via `enable_generate_secrets = false` and provide your own via `values`/`values_yaml`.

### Configuration (kratos.config)

You can pass your Kratos configuration similar to a `kratos.yml` by using `kratos_config`, which is merged under `kratos.config`.

Example (mapping from a `kratos.yml`):

```hcl
module "kratos" {
  source    = "../ory/kratos"
  namespace = "auth"

  kratos_config = {
    log = { level = "info" }
    serve = {
      public = { host = "0.0.0.0", port = 4433, base_url = "https://forge-test.projectcatalyst.io/.ory/kratos/public" }
      admin  = { host = "0.0.0.0", port = 4434 }
    }
    secrets = {
      # Usually generated automatically by this module; can be overridden here
      # default = ["..."]
      # cookie  = ["..."]
      # cipher  = ["..."]
    }
    selfservice = {
      default_browser_return_url = "https://forge-test.projectcatalyst.io/"
      allowed_return_urls        = ["https://forge-test.projectcatalyst.io/*"]
      flows = {
        settings     = { ui_url = "https://forge-test.projectcatalyst.io/profile" }
        login        = { ui_url = "https://forge-test.projectcatalyst.io/welcome" }
        error        = { ui_url = "https://forge-test.projectcatalyst.io/auth/error" }
        registration = {
          ui_url = "https://forge-test.projectcatalyst.io/welcome"
          after  = { oidc = { hooks = [{ hook = "session" }] } }
        }
      }
      methods = {
        passkey = {
          enabled = true
          config  = { rp = { display_name = "Catalyst Forge", id = "forge-test.projectcatalyst.io", origins = ["https://forge-test.projectcatalyst.io"] } }
        }
        oidc = {
          enabled = true
          config  = {
            providers = [
              { id = "github", provider = "github", client_id = var.github_client_id, client_secret = var.github_client_secret, scope = ["user:email", "read:org"], mapper_url = "file:///etc/kratos/github.mapper.jsonnet" },
              { id = "google", provider = "google", client_id = var.google_client_id, client_secret = var.google_client_secret, issuer_url = "https://accounts.google.com", mapper_url = "file:///etc/kratos/google.mapper.jsonnet", scope = ["openid","email","profile"] }
            ]
          }
        }
      }
    }
    session = { cookie = { domain = "forge-test.projectcatalyst.io", same_site = "Lax", persistent = true, path = "/" } }
    identity = { default_schema_id = "default" }
    # IMPORTANT: leave `dsn` empty to avoid plaintext secrets; use `dsn_secret` input instead to inject via env.
    # version: optional chart value elsewhere
  }
}
```

### Identity schema support

Provide one or more identity schemas via `identity_schemas` (map of ID -> JSON schema content). The module will mount schemas and configure Kratos to use them. Set `identity_default_schema_id` to choose the default when multiple are provided.

Example:

```hcl
module "kratos" {
  source    = "../ory/kratos"
  namespace = "auth"

  identity_schemas = {
    default = jsonencode({
      "$id" : "https://schemas.ory.sh/presets/kratos/identity.email.schema.json",
      "$schema" : "http://json-schema.org/draft-07/schema#",
      "title" : "Person",
      "type" : "object",
      "properties" : {
        "traits" : {
          "type" : "object",
          "properties" : {
            "email" : {
              "type" : "string",
              "format" : "email",
              "ory.sh/kratos" : { "credentials" : { "password" : { "identifier" : true } } }
            }
          },
          "required" : ["email"],
          "additionalProperties" : false
        }
      }
    })
  }

  identity_default_schema_id = "default"
}
```

### DSN via SecretRef (best practice)

Avoid storing DSN in plaintext config. Provide a SecretRef and the module will inject env var across deployment, job, and cleanup cronjob:

```hcl
dsn_secret = {
  name = "dsn-secret"
  key  = "dsn"
  # env_name = "DSN"  # optional override
}
```

### OIDC mapper files

If your providers reference local mapper files (e.g., `file:///etc/kratos/github.mapper.jsonnet`), pass them via `oidc_mappers` and the module will create a ConfigMap and mount it at `/etc/kratos` for both the deployment and migration job.

```hcl
oidc_mappers = {
  "github.mapper.jsonnet" = file("${path.module}/github.mapper.jsonnet")
  "google.mapper.jsonnet" = file("${path.module}/google.mapper.jsonnet")
}
```

Ensure your `kratos_config.selfservice.methods.oidc.config.providers[*].mapper_url` points to `file:///etc/kratos/<filename>`, matching the keys above.

## Inputs

- `name` (string): Helm release name. Default: `kratos`
- `namespace` (string): Target namespace. Required.
- `repository` (string): Helm repo URL. Default: `https://k8s.ory.sh/helm/charts`
- `chart_version` (string): Helm chart version. Optional.
- `values` (map): Additional values as HCL map; encoded to YAML and applied before `values_yaml`. Default: `{}`.
- `values_yaml` (string): Additional YAML values, applied after generated + map values. Default: empty.
- `kratos_config` (any): Raw Kratos configuration merged under `kratos.config`.
- `dsn_secret` (object): `{ name, key, env_name? }` SecretRef used to inject DSN env into deployment, job, and cronjob.cleanup.
- `identity_schemas` (map(string)): Map of schema ID to JSON schema content. Default: `{}`.
- `identity_default_schema_id` (string): Default schema ID when multiple schemas are provided. Must exist in `identity_schemas` if that map is non-empty. Default: `default`.
- `create_namespace` (bool): Create namespace. Default: `true`.
- `wait` (bool): Wait for readiness. Default: `true`.
- `timeout_seconds` (number): Helm timeout. Default: `600`.
- `enable_generate_secrets` (bool): Generate Kratos secrets. Default: `true`.
- `enable_automigration` (bool): Toggles `kratos.automigration.enabled`. Default: `true`.
- `secret_length` (number): Generated secret length. Default: `32`.
- `oidc_mappers` (map(string)): filename -> content for mapper files. Mounted at `/etc/kratos`.
- `http_route` (object|null): Gateway API HTTPRoute config. Fields: `{ enabled, name?, namespace?, parent_ref { name, namespace?, sectionName? }, hostnames, rules? }`.

## HTTPRoute (Envoy Gateway)

If deploying with Catalyst Forge and Envoy Gateway, you can enable an HTTPRoute that targets the public service:

```hcl
http_route = {
  enabled = true
  parent_ref = {
    name = var.gateway_name
    namespace = var.gateway_namespace # optional if same as module namespace
    # sectionName = "https" # optional
  }
  hostnames = ["kratos.example.com"]
  # Optional custom rules; default routes "/" to the Kratos public service on port 80
  # rules = [
  #   {
  #     matches = [{ path = { type = "PathPrefix", value = "/" } }]
  #     backendRefs = [{ name = "kratos-public", port = 80 }]
  #   }
  # ]
}
```

## Outputs

- `release_name`: Helm release name.
- `namespace`: Namespace deployed to.
- `chart_version`: Chart version used.
- `generated_cookie_secret` (sensitive): Cookie secret if generated.
- `generated_cipher_secret` (sensitive): Cipher secret if generated.
- `generated_default_secret` (sensitive): Default secret if generated.

## Requirements

- Terraform >= 1.5.0
- Providers: helm (>= 2.12.1), kubernetes (>= 2.27.0), random (>= 3.6.0)
